# Task 1 - Landing Page

## Sim & Sip ☕

Sim & Sip is a responsive café landing page created using HTML and CSS as part of the OASIS INFOBYTE Web Development Internship.

### Features

- Fixed navigation bar
- Responsive hero section
- About section
- Café menu cards
- Why Sim & Sip section
- Customer reviews section
- Contact section
- Responsive design for desktop and mobile
- Custom Simme-inspired line art

### Technologies Used

- HTML5
- CSS3
- Flexbox
- CSS Grid
- Responsive Media Queries
